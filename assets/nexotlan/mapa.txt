#  MODO AVENTURA · NEXOTLAN — MAPA, DISTRITOS Y PERSONAJES
#  Edita este archivo con el Bloc de notas (guárdalo en UTF-8).
#  Mismo estilo que assets/arcade/rivales.txt:  campo = valor
#
#  TIP: abre  nexotlan.html?editor=1  para mover los puntos con el dedo/ratón
#       y copiar este archivo ya con las coordenadas nuevas.
#
#  OJO: el ID entre corchetes ([distrito:puerta], [punto:vika]) es la identidad del punto o distrito.
#       Si lo cambias, el juego lo trata como uno nuevo; usa  antes = id_viejo  para conservar el progreso.
#
#  Hay 3 tipos de bloque:
#   [config]            ajustes generales
#   [distrito:ID]       una zona del mapa (ID sin espacios: puerta, mercado…)
#   [punto:ID]          un rival, héroe o guardián en el mapa (ID único, sin espacios)
#
#  ── [config] ──
#   titulo, subtitulo
#   fondo_titulo  imagen de fondo de la portada (en assets/nexotlan/titulo/ o directo en assets/nexotlan/). Vacío = la de siempre
#   logo          logo de la portada en lugar del texto del título (PNG transparente, misma carpeta). Vacío = el texto
#   mapa        imagen del mapa en assets/nexotlan/ (ej. mapa.jpg). Vacío = mapa neón generado
#   musica      música del mapa (ruta como en el Arcade, ej. musica_choque/pista_9.mp3)
#   musica_choque (opcional) música de los Choques de todo el modo (si el distrito o el punto no tienen una)
#   dias        nombres de los días separados por coma
#   excluir_habilidades  cartas con (o que otorgan) estas habilidades no se usan en el modo:
#               no salen de premio ni en la tienda y no entran a la baraja. Vacío = ninguna
#   fondo_mesa  fondo detrás del tablero en los Choques: imagen en assets/nexotlan/simulador/ (ej. mesa.jpg)
#               o un tema del Simulador: nexo, obsidiana, grecas, jade, mar, fuego, cristal, mictlan, metal
#   playmat     imagen del tablero en los Choques (assets/nexotlan/simulador/). Vacío = el del jugador
#   fondo_inicio imagen de la pantalla de inicio del Choque. Vacío = el paisaje del distrito
#   (los tres también se pueden poner en un [distrito:…] o en un [punto:…] para cambiarlos ahí)
#
#  ── [distrito:ID] ──
#   nombre, descripcion, color
#   x, y        centro del distrito en el mapa (en %, 0-100)
#   radio       tamaño aproximado (en %) para el mapa neón generado
#   forma       (opcional) contorno exacto: puntos "x,y x,y x,y …" en %
#   etiqueta    (opcional) dónde va el nombre del distrito: "x,y" en %
#   requiere    ID del punto que hay que vencer para abrirlo (vacío = abierto desde el inicio)
#   musica      (opcional) música al seleccionar este distrito
#   musica_choque (opcional) música de TODOS los Choques de este distrito (un punto con musica = … la cambia)
#   paisaje     (opcional) imagen panorámica angosta en assets/nexotlan/paisajes/ (ej. 1600×500 px)
#               aparece detrás de los rivales y héroes de este distrito al hablar con ellos
#
#  ── [punto:ID] ──
#   tipo        rival | heroe | guardian
#               rival = jugador que explora Nexotlan · heroe = personaje del juego de cartas que te habla · guardian = jefe del distrito
#   nombre, titulo, distrito
#   x, y        posición en el mapa (en %)
#   dias        días en que aparece, por sus 3 primeras letras (lun, mar, mie…). Vacío = todos
#   imagen      PNG del personaje en assets/nexotlan/personajes/
#               (o con carpeta: arcade/personajes/rival_01.png toma la del Arcade)
#   carta       id o nombre de una carta: su arte se usa si falta la imagen
#   baraja      id de la baraja de la CPU (rival y guardian)
#   dificultad  facil | medio | dificil | muy_dificil | auto  (auto = según el distrito)
#   corazones   corazones EXTRA de la CPU
#   musica      música del Choque (la partida)
#   paisaje     (opcional) paisaje propio de este punto (si no, usa el de su distrito)
#   requiere    ID de punto que hay que vencer/visitar antes de que aparezca
#   antes       (opcional) IDs que tuvo este punto antes de renombrarlo: conserva lo que el jugador ya hizo
#               con él (no vuelve a dar monedas ni a pedir el Choque). Ej. antes = koatl
#   monedas     monedas que da al vencerlo (rival/guardian) o al hablarle la 1a vez (heroe)
#   entrada     lo que dice al acercarte          (usa | para separar cuadros de diálogo)
#   victoria    lo que dice cuando TÚ ganas
#   derrota     lo que dice cuando TÚ pierdes
#   revancha    lo que dice si ya lo venciste antes
#   dialogo     (heroe) lo que dice la primera vez
#   dialogo2    (heroe) lo que dice las siguientes veces
#   musica_dialogo (opcional) música mientras hablas con este personaje (al cerrar regresa la del mapa)
#   ── Jefes de 2 fases (opcional): al vencer la 1ª forma se transforma y empieza otro Choque ──
#   fase2_baraja      baraja de la 2ª forma (si este campo existe, el punto tiene 2 fases)
#   fase2_nombre, fase2_titulo, fase2_imagen, fase2_carta, fase2_paisaje   cómo se ve transformado
#   fase2_musica      música del 2º Choque · fase2_musica_dialogo  música al hablar con la 2ª forma
#   fase2_corazones, fase2_dificultad, fase2_etiqueta (texto del VS, ej. FORMA VERDADERA)
#   fase2_entrada     lo que dice al transformarse · fase2_revancha  si vuelves a retar su 2ª forma
#   fase2_victoria / fase2_derrota   lo que dice al final (si no, usa victoria / derrota)
#   fase2_reintento   si = al perder, reintentas directo la 2ª forma · inicio = vuelves a empezar desde la 1ª
#
#  Las líneas que empiezan con # son comentarios.
