# Una mesa por línea, con los campos separados por "|":
#
#   id | Nombre | archivo | descripción | barajas (opcional)
#
#   id ........... corto, sin espacios ni acentos (selva, volcan, mictlan_rio…). No lo cambies después:
#                  es lo que se guarda como elección del jugador.
#   Nombre ....... lo que se ve en ⚙ → Apariencia.
#   archivo ...... imagen dentro de esta carpeta (assets/simulacion/mesas/). También acepta una URL completa.
#   descripción .. texto pequeño bajo el nombre.
#   barajas ...... ids de baraja que usan esta mesa con "Según tu baraja", separados por coma.
#
# Imágenes: vista cenital (desde arriba), unos 2400 × 2100 px, JPG calidad 80–85.
# Las líneas que empiezan con # se ignoran.
#
